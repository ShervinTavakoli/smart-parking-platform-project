# Smart Parking Platform

## Overview
The Smart Parking Platform is a web and mobile application that helps drivers locate, reserve, navigate to, and pay for parking spaces in real time.

## Business Need
Drivers spend significant time searching for parking spaces, causing congestion and frustration. Parking operators also need better occupancy and management tools.
